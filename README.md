# Orgnomics

Orgnomics is a Neovim plugin that enhances the Neovim Orgmode experience. It provides
Snacks Picker integration for headlines and Org files, along with a clock manager.

This plugin is currently undocumented. Stay tuned for updates, and feel free to use it
if you find it useful.
